# Trivia Overflow

Juego de preguntas para estudiar **Complementos de Matemática II**. Cada partida tiene 8 preguntas y cada respuesta correcta enciende un bit de un byte: la pregunta 1 vale 128 y la 8 vale 1, así que el puntaje va de 0 a 255.

**Jugar online:** https://mariomerida88.github.io/m88_game_TriviaOverflow/

## Características

- 350 preguntas sobre los 10 capítulos del apunte, con selección simple y múltiple.
- Elegís qué capítulos estudiar; cada pregunta indica dónde verificarla (Def., Teo., Ej., Ejercicio).
- Récord, mejor racha y capítulos elegidos se guardan en el navegador (`localStorage`).
- HTML, CSS y JavaScript puros, sin build ni dependencias (sólo Google Fonts).

Para jugar localmente, abrí `index.html` en el navegador.
